Bauplan offers two deployment options, on any of the [supported clouds](#supported-clouds).

## Single-tenant Private Link deployment

In this model, Bauplan manages a dedicated cloud environment for you,
linked to your own object storage:

```mermaid
flowchart TB
    A["<b>Your Local Environment</b><br/>(IDE / CLI / SDK)"]

    A -->|"auth + data streaming<br/>(private link)"| B

    subgraph B["Bauplan Managed Cloud"]
        direction TB
        C["<b>Bauplan APIs</b><br/>(Data Catalog)"]:::accent
        D["<b>Data Plane</b><br/>(compute runtime)"]:::accent
    end

    B --> E["<b>Your Bucket</b><br/>(in your cloud account)"]:::external
```

<DiagramLegend />

Key Benefits:

- Fully isolated, SOC2-compliant managed environment.
- Data stays in your cloud with no egress costs.
- No infrastructure management required by your team.

## Bring your own cloud (BYOC) deployment

In the BYOC model, the entire Bauplan runtime is deployed within your
existing VPC, under your control:

```mermaid
flowchart TB
    A["<b>Your Local Environment</b><br/>(IDE / CLI / SDK)"]

    A -->|"auth + data streaming"| B

    subgraph B["Your Cloud (BYOC - VPC)<br/>(compute runs here only)"]
        direction TB
        C["<b>Data Plane</b><br/>(compute runtime)"]
        E["<b>Object Storage</b><br/>(Your Bucket)"]:::external
        C --> E
    end

    B <--> F

    F["<b>Bauplan APIs</b><br/>(Control Plane)<hr/><ul><li>Catalog (Iceberg + Git-for-data)</li><li>Auth, scheduling, observability</li><li>Multi-tenant, managed by Bauplan</li></ul>"]:::accent
```

<DiagramLegend />

Key Benefits:

- Maximum security and control within your infrastructure.
- No external data traffic, fully private and compliant.
- Efficient, with zero data transfer costs to external networks.

## Supported clouds

Bauplan runs on the following clouds, with the data plane in the same cloud as the bucket that holds your data:

- **Amazon Web Services**, with data in S3.
- **Google Cloud**, with data in Cloud Storage.

The control plane is managed by Bauplan and does not depend on your cloud. The same commands, SDK methods, and pipelines work on every supported cloud.

Cloudflare R2 is not a native storage option, but Parquet files in an R2 bucket can be registered as external tables through the [R2 integration](/integrations/warehouses-lakehouses/r2-cloudflare-object-storage), currently in preview.

[Contact us](https://www.bauplanlabs.com/contact) if you need support for another cloud or object storage service.
