[Metabase](https://www.metabase.com/) is an open source BI tool.

The Bauplan plugin adds Bauplan as a database type in Metabase. Queries run on Bauplan, authenticated with your API key.

With the plugin you can:

- Browse Bauplan namespaces, tables, and columns.
- Build questions with the query builder or in SQL.
- Build dashboards on Bauplan tables.
