[TextQL](https://textql.com/) is an AI data analysis platform. Its assistant, Ana, answers natural language questions by writing and running SQL and Python, and shows the query behind each answer.

TextQL builds an ontology on top of connected data: a semantic layer of metric definitions, entity relationships, and business context that keeps answers consistent across questions.

With the Bauplan integration, TextQL uses Bauplan as a data source, so you can query Bauplan tables in natural language.
